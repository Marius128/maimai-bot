# KokaBot 使用手册

KokaBot 是一个舞萌 DX QQ 群机器人，可以查询 B50、更新查分器成绩，也可以记录和查询机厅人数。

机器人管理员：迪亚（QQ：805670312）

如果机器人提示配置错误、适配器没有启动，或者多次操作都失败，请联系管理员。

## 先记住这两件事

1. 在群里使用 `/` 开头的指令时，需要先 `@机器人`。
2. 绑定账号时涉及授权码、Import-Token 和玩家二维码，请务必私聊机器人，不要发到群里。

例如，在群里查询 B50：

```text
@机器人 /b50
```

私聊机器人时不用 @，直接发送指令即可。

## 一、查询 B50

### 生成 B50 图片

```text
/b50
```

机器人会按照你当前选择的数据源，读取你的成绩并生成 Best 50 图片。

如果提示找不到成绩，请先确认：

- 你已经在对应查分器注册；
- 查分器绑定的是你现在发指令的 QQ；
- 查分器里已经有你的舞萌成绩；
- 没有在查分器中关闭第三方成绩查询。

## 二、选择成绩来源

机器人支持两个查分器：水鱼和落雪。每个人可以自己选择，互不影响。

### 查看当前使用哪个查分器

```text
/source
```

### 切换到水鱼

```text
/source fish
```

### 切换到落雪

```text
/source lxns
```

切换后，`/b50` 会从这个查分器读取成绩，`/update` 也会把成绩更新到这个查分器。

## 三、绑定落雪

绑定操作请全部私聊机器人完成。

### 开始绑定或重新授权

```text
/bind lxns
```

机器人会发一条落雪授权链接。打开链接完成授权，再把网页显示的授权码私聊发给机器人：

```text
/bind lxns 你的授权码
```

### 查看是否已经绑定

```text
/bind lxns status
```

### 解除绑定

```text
/unbind lxns
```

解除后，机器人会删除保存的落雪授权。你也可以在落雪的第三方应用页面撤销授权。

## 四、绑定水鱼

先登录水鱼查分器，在个人资料页面生成并复制 `Import-Token`，然后私聊机器人发送：

```text
/bind fish 你的Import-Token
```

不要把 Import-Token 发到群里，它相当于账号凭证。

### 查看是否已经绑定

```text
/bind fish status
```

### 解除绑定

```text
/unbind fish
```

## 五、绑定舞萌账号

这一步是为了让机器人能够从机台侧读取你的成绩，使用 `/update` 前必须完成。

在微信中打开舞萌玩家二维码，长按识别二维码内容，复制以 `SGWCMAID` 开头的完整字符串，然后私聊机器人发送：

```text
/bind mai SGWCMAID...
```

二维码内容属于敏感凭证，不要发到群里。

### 查看是否已经绑定

```text
/bind mai status
```

### 解除绑定

```text
/unbind mai
```

机器人不会保存你发来的原始二维码，只会保存验证后得到的加密玩家标识。

## 六、快捷更新成绩

先选择水鱼或落雪，再完成对应查分器绑定和舞萌账号绑定，最后发送：

```text
/update
```

例如，想把成绩更新到落雪：

```text
/source lxns
/bind lxns
/bind mai
/update
```

想更新到水鱼，则使用：

```text
/source fish
/bind fish
/bind mai
/update
```

实际绑定时，请根据机器人的提示补上授权码、Import-Token 或 `SGWCMAID...`。

快捷更新会先比较成绩，只上传新增或提高的记录；完全相同或更差的成绩会跳过，避免重复上传。

目前快捷更新只能可靠同步达成率和 DX 分数，不包含 FC、FC+、AP、AP+ 与同步标志。它不会把查分器里已有的徽章清空。

## 七、汇报和查询机厅人数

机厅人数功能只在群聊使用，而且不需要 @机器人。

每个群单独记录人数，不会把其他群的汇报混进来。目前支持光大和永利，两边都按 1 台机、每轮最多 2 人计算。

### 汇报光大人数

下面三种说法都可以，数字可以换成实际人数：

```text
g5
光大5
光5
```

### 查询光大人数

```text
g几
gj
光大几个
光大几
光几
```

### 汇报永利人数

```text
y5
永利5
永5
```

### 查询永利人数

```text
y几
yj
永利几个
永利几
永几
```

查询时，机器人会告诉你最近一次汇报的人数、预计等待时间、汇报人和汇报时间。

例如：

```text
📍 光大当前人数：5 人
🕹️ 机台数量：1 台（每轮 2 人）
⏳ 新到预计等待 2 轮（约 30 分钟）。
📣 汇报人：@某位群友
🕒 汇报时间：2026-09-21 10:24:00
```

人数是群友主动汇报的，不是机厅实时自动统计。时间过去较久时，建议到店前再向群友确认。

## 八、查看机器人帮助

```text
/help
```

机器人会发送一份精简版常用指令说明。

## 九、常见问题

### 为什么在群里发 `/b50` 没反应？

群里的 `/` 指令需要先 @机器人，例如：

```text
@机器人 /b50
```

机厅人数的 `g5`、`g几`、`y5`、`y几` 不用 @。

### 为什么 B50 提示找不到成绩？

一般是当前数据源中没有找到与你 QQ 对应的玩家。请确认 QQ 绑定、数据源选择和查分器隐私设置。

### 为什么 `/update` 提示没有绑定？

快捷更新需要两类绑定：

- 当前数据源是落雪：需要 `/bind lxns` 和 `/bind mai`；
- 当前数据源是水鱼：需要 `/bind fish` 和 `/bind mai`。

### 为什么更新后没有 FC、AP 或同步标志？

当前机台快捷数据不提供这些信息，所以快捷更新暂时只保证达成率和 DX 分数。

### 授权失效怎么办？

根据提示重新私聊执行 `/bind lxns`、`/bind fish` 或 `/bind mai` 即可替换旧绑定。

### 机器人现在支持完整更新、签到积分或附近机厅吗？

暂不支持。当前正式功能以本手册列出的内容为准。

## 十、隐私提醒

- 授权码、Import-Token 和 `SGWCMAID...` 只能私聊机器人；
- 不要截图发群，也不要转发给其他人；
- 落雪 Token、水鱼 Import-Token 和舞萌玩家标识会加密后保存；
- 不再使用时，可以通过对应的 `/unbind` 指令删除机器人保存的绑定信息。
